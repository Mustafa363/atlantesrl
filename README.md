# Dash Runner

نسخة مستوحاة من Geometry Dash بلغة عربية وتخطيط متجاوب.

## طريقة التشغيل محليًا

يمكن تشغيل اللعبة كصفحة ويب ثابتة. افتح مجلد المشروع وشغّل خادمًا محليًا ثم انتقل للعنوان المحلي في المتصفح.

### باستخدام Python 3
```bash
python -m http.server 8000
```
ثم افتح [http://localhost:8000](http://localhost:8000).

### باستخدام Node.js (npx)
```bash
npx http-server -p 8000
```

بعد تشغيل الخادم ستجد اللعبة في الصفحة الرئيسية `index.html` وتعمل على الموبايل والكمبيوتر.
